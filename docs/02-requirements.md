# Требования и критерии приёмки

| Код | Требование | Условие приёмки |
|---|---|---|
| FR-01 | Ведение задач | Создание, редактирование и удаление доступны в интерфейсе |
| FR-02 | Приоритет и оценка | Приоритет из трёх значений; оценка 0, 1, 2, 3, 5, 8 или 13 |
| FR-03 | Kanban | Доступны backlog, todo, progress и done |
| FR-04 | WIP | Четвёртая задача в состоянии progress отклоняется |
| FR-05 | Спринты | У спринта есть название и корректный диапазон дат |
| FR-06 | Фильтр | Выбранный спринт ограничивает отображаемые задачи |
| FR-07 | Сохранение | После перезагрузки данные сохраняются в том же браузере |
| FR-08 | Резервная копия | JSON экспортируется, проверяется и импортируется |
| NFR-01 | Доступность | Все основные действия доступны с клавиатуры, поля имеют подписи |
| NFR-02 | Проверка данных | Пустое название, неизвестный статус и некорректный импорт отклоняются |
| NFR-03 | Развёртывание | Работает через стандартный локальный HTTP-сервер без внешних библиотек |

Примеры пользовательских историй:

1. Как пользователь, я хочу оценить задачи, чтобы выбирать посильный объём спринта.
2. Как пользователь, я хочу видеть незавершённую работу, чтобы ограничить переключения.
3. Как пользователь, я хочу экспортировать задачи, чтобы сохранить резервную копию.

Вне текущей версии: командные роли в приложении, серверная база, авторизация, календарные уведомления и мобильная синхронизация.

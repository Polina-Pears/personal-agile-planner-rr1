# Сопровождение

Перед изменением модели повысить или сохранить версию формата осознанно,
проверить импорт существующих копий, выполнить тесты модели и сценарии браузера.
Изменение считается готовым после проверки и включения в основную ветку.

Следующие улучшения: редактирование спринта, календарь, поиск по задачам,
проверка доступности экранным диктором. Облачная синхронизация потребует
серверной части, аутентификации и отдельной модели доступа.

В учебном обмене с локальным внешним репозиторием используется вторая рабочая
копия того же автора. Она не изображает отдельного участника команды.

Контрольный обмен: изменения из второй локальной копии получены через fetch и pull.

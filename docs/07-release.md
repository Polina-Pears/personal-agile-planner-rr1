# Выпуск 1.0

В прототип вошли операции с задачами, спринты, фильтры, ограничение WIP,
сохранение в браузере, экспорт и импорт JSON. Критерии приёмки локального
прототипа выполнены. Проект опубликован в публичном репозитории
https://github.com/Polina-Pears/personal-agile-planner-rr1.
История разработки, семь веток этапов, main и метка v1.0 отправлены на GitHub.

Для запуска открыть каталог проекта, выполнить `python -m http.server 8767`
и перейти по адресу `http://localhost:8767`. Использовать один и тот же адрес
при повторном открытии: localStorage относится к источнику страницы.

Резервная копия данных создаётся кнопкой «Экспорт». Для восстановления выбрать
«Импорт», указать JSON и подтвердить замену. Очистка данных браузера удалит
локальные задачи; резервная копия должна храниться отдельно.

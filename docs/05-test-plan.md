# План проверки

Автоматические проверки модели запускаются командой `node --test tests/model.test.cjs`.
Они проверяют добавление, изменение, удаление, лимит WIP, связи со спринтами,
календарные даты, импорт и экспорт. Исходное состояние не должно изменяться
при ошибке операции. Входные данные с неизвестной версией отклоняются.

Проверка в браузере выполняется отдельно:

1. Создать спринт, указать даты, выбрать его в фильтре.
2. Создать задачи с приоритетом и оценкой, изменить статус.
3. Перезагрузить страницу и убедиться, что данные сохранились.
4. Проверить фильтр приоритета и редактирование задачи.
5. Довести число задач в работе до трёх и проверить отказ для четвёртой.
6. Проверить узкое окно, отсутствие горизонтального переполнения и видимость кнопок.

Область проверки: текущий браузер и модель данных. Облачная синхронизация,
пользовательские учётные записи и многопользовательская работа не реализованы.

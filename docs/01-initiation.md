# Паспорт проекта

Название: личный Agile-планировщик.

Основание: рейтинговое задание по дисциплине «Проектная деятельность в ИТ», вариант по первой букве фамилии В–Д.

Проблема: личные задачи хранятся разрозненно, а одновременная работа над большим числом дел затрудняет завершение начатого.

Цель: дать одному пользователю инструмент ведения бэклога, отбора задач в спринт и контроля статусов.

Результаты: работающий браузерный прототип, требования, ИСР, модель данных, проверки и версия в Git.

Критерии успеха: задача проходит все четыре состояния; некорректные поля отклоняются; состояние сохраняется после перезагрузки; данные можно экспортировать и восстановить; проверки модели проходят.

Ограничения: локальное хранение, один пользователь, отсутствие облачной синхронизации. Экспорт JSON служит резервной копией данных.

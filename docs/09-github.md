# Публикация и проверка GitHub

Публичный репозиторий: https://github.com/Polina-Pears/personal-agile-planner-rr1

Владелец репозитория — Polina-Pears. Видимость Public. Исходные коммиты
сохранены с первоначальными данными автора учебного проекта. Доступ на запись
другим участникам не предоставлялся; защита отдельных веток не настраивалась.

## Выполненные действия

1. Создан пустой публичный репозиторий без начальных файлов.
2. В существующем проекте добавлен origin с HTTPS-адресом репозитория.
3. Команда `git push --set-upstream origin main` связала основную ветку с origin/main.
4. Выполнены `git push origin --all` и `git push origin --tags`.
5. Проект клонирован по публичному HTTPS-адресу в отдельную папку.
6. В клоне изменён документ сопровождения, создан и отправлен коммит 65393c9.
7. В исходном проекте выполнены `git fetch origin`, просмотр разницы истории
   `git log --oneline HEAD..origin/main` и `git pull --ff-only origin main`.
   Основная ветка продвинута с 33a5854 до 65393c9, рабочий каталог остался чистым.
8. Страница репозитория открыта без входа в GitHub; видны Public, файлы проекта,
   восемь веток и метка выпуска.

Обе рабочие копии использованы одним автором для контрольного опыта.
Фактическое получение обновления с сервера проверено отдельно от ранее
проведённого локального обмена с учебным репозиторием practice.

Авторизация отправки выполнена через установленный GitHub CLI и его
штатное хранилище учётных данных. Пароли и токены в проект не включены.

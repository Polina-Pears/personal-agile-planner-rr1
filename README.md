# Личный Agile-планировщик

Учебный проект по дисциплине «Проектная деятельность в ИТ»: планирование личного бэклога, спринтов и работы на Kanban-доске.

## Возможности

- Создание и редактирование задач: описание, приоритет, оценка в story points и спринт.
- Четыре состояния: бэклог, к выполнению, в работе, готово.
- Ограничение одновременно выполняемых задач: не более трёх.
- Создание спринтов с проверкой дат и фильтрация доски по спринту.
- Сохранение в браузере, экспорт и импорт JSON.

## Запуск

Требуется Python 3 для локального сервера и современный браузер. Установка библиотек не нужна.

```text
python -m http.server 8767 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8767 в браузере. Сервер запускается из корня проекта.

Данные хранятся в localStorage выбранного браузера для этого адреса. Для переноса используйте экспорт JSON. Очистка данных сайта удаляет локальное состояние; резервный файл следует хранить отдельно.

## Проверка

Для автоматических проверок модели требуется Node.js 20 или новее:

```text
node --test tests/model.test.cjs
```

## Устройство проекта

```text
index.html       интерфейс
src/model.js     правила работы с задачами и спринтами
src/app.js       взаимодействие интерфейса с моделью
src/styles.css   оформление
tests/          автоматические проверки
docs/           требования, ИСР, архитектура и приёмка
```

## Область применения

Приложение рассчитано на личное планирование одним человеком в одном браузере. В нём нет серверной регистрации, совместного редактирования, уведомлений или облачной синхронизации. Это рабочий прототип, а не промышленная система управления проектами.

Документация жизненного цикла находится в [docs](docs/). Ветки `01-initiation`–`07-maintenance` фиксируют соответствующие этапы работ; `main` содержит принятую версию.

Ветки отражают результаты этапов, а не встроенную систему разграничения доступа. Git сам по себе не назначает права на отдельные ветки.

## Категории участников

В личном проекте владелец выполняет анализ, разработку и приёмку. Для публичного репозитория GitHub владелец управляет настройками, посетитель может читать и клонировать открытый код. Дополнительные соавторы не приглашены. Если появится соавтор, доступ на запись выдаётся отдельно; правила ревью и защиты main настраиваются на сервере.
